# Python Profile Card Generator

A beginner-friendly Python mini project that takes user details, cleans the input, extracts the username from the email, and prints a formatted profile card.

## Features
- Takes user input: name, email, phone, city, course
- Cleans input using basic string methods (`strip`, `title`, `lower`, `replace`)
- Extracts username from email (text before `@`)
- Handles invalid email when `@` is missing

## Requirements
- Python 3.x

## How to Run
1. Download this repository (or clone it).
2. Open a terminal in the project folder.
3. Run:

```bash
py profile_card.py
